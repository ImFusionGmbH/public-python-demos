# Registration Demos with `imfusion-sdk-registration`

This folder contains Jupyter notebooks demonstrating image registration with the `imfusion-sdk-registration` Python package.

**Note:** The `imfusion-sdk-registration` package is part of the Free plan for non-commercial research use.

## Setup

1. Please follow the steps described in [imfusion-sdk/README.md](../imfusion-sdk/README.md) for the initial environment setup.

2. Install dependencies for this demo:

```bash
(demo-env) pip install -r imfusion-sdk-registration/requirements.txt
```

3. Start Jupyter in this folder:

```bash
(demo-env) cd imfusion-sdk-registration/
(demo-env) jupyter notebook
```
