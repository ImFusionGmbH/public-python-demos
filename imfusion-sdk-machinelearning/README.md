# Machine Learning Demos with `imfusion-sdk-machinelearning`

This folder contains Jupyter notebooks demonstrating data pipelines and model inference with the `imfusion-sdk-machinelearning` Python package.

**Note:** The `imfusion-sdk-machinelearning` package is part of the Free plan for non-commercial research use.

## Setup

1. Please follow the steps described in [imfusion-sdk/README.md](../imfusion-sdk/README.md) for the initial environment setup.

2. Install dependencies for this demo:

```bash
(demo-env) pip install -r imfusion-sdk-machinelearning/requirements.txt
```

3. Start Jupyter in this folder:

```bash
(demo-env) cd imfusion-sdk-machinelearning/
(demo-env) jupyter notebook
```
