# Labels Demos with `imfusion-sdk-labels`

This folder contains Jupyter notebooks demonstrating how to create, inspect, and modify ImFusion Labels projects with the `imfusion-sdk-labels` Python package.

**Note:** The `imfusion-sdk-labels` package is available through our [ImFusion Labels plans](https://imfusion.com/labels-pricing/).

## Setup

1. Please follow the steps described in [imfusion-sdk/README.md](../imfusion-sdk/README.md) for the initial environment setup.

2. Install dependencies for this demo:

```bash
(demo-env) pip install -r imfusion-sdk-labels/requirements.txt
```

3. Start Jupyter in this folder:

```bash
(demo-env) cd imfusion-sdk-labels/
(demo-env) jupyter notebook
```
