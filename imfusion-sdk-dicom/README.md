# DICOM Demos with `imfusion-sdk-dicom`

This folder contains Jupyter notebooks showing how to work with DICOM images, RT Structure Sets, and DICOM Segmentation I/O with the `imfusion-sdk-dicom` Python package.

**Note:** The `imfusion-sdk-dicom` package is part of the Free plan for non-commercial research use.

## Setup

1. Please follow the steps described in [imfusion-sdk/README.md](../imfusion-sdk/README.md) for the initial environment setup.

2. Install dependencies for this demo:

```bash
(demo-env) pip install -r imfusion-sdk-dicom/requirements.txt
```

3. Start Jupyter in this folder:

```bash
(demo-env) cd imfusion-sdk-dicom/
(demo-env) jupyter notebook
```
